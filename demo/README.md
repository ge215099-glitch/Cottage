# Cottage Demo

单文件界面 Demo，用于验证 `docs/ui-design-sidebar-chat.md` 与 `docs/ui-design-conversation.md` 里的布局与交互。

**纯前端 · 无后端 · 无网络请求**：所有会话、消息、摘要、token 数均为内存中的模拟数据，关闭页面即丢失。

## 打开

直接双击 `demo/index.html`（`file://` 即可，无需构建、无需服务器）。

## 交互速查

| 操作 | 位置 |
|---|---|
| 悬停会话行 → 出现 `⋯` | 左栏列表；`⋯` → 重命名 / 置顶 / 删除 |
| 重命名 | 双击会话标题，或 `⋯ → 重命名`，或行聚焦后 `F2` |
| 删除 | `⋯ → 删除`（含消息数与摘要段数的二次确认） |
| 置顶 | `⋯ → 置顶`，或主区顶栏的 📌 |
| 搜索 | 左栏搜索框，或 `Ctrl/⌘ + K` |
| 新对话 | 左栏「新对话」，或 `Ctrl/⌘ + N` |
| 侧栏拉出 / 收起 | `Ctrl/⌘ + B`，或品牌行的折叠钮（双击品牌行也行）——**只有两态，不可拖宽** |
| 详情栏拉出 / 收起 | 顶栏 `⧉`，或 `Ctrl/⌘ + I`——固定 320px，同样不可拖宽 |
| 右栏标签 | `Ctrl/⌘ + 1/2/3/4` = 上下文 / 对话 / 角色 / 数据 |
| 消息操作 | 悬停消息 → 复制 / 编辑 / 重新生成 / `⋯` |
| 发送 / 停止 | `Enter` 发送，`Shift+Enter` 换行；生成中同一按钮变「停止」 |
| 上下文占用 | 输入框右下角常驻；`≥75%` 转警告色，`≥80%` 触发模拟自动压缩 |
| 压缩 | 右栏「上下文」→「压缩最老的 N 条」，可取消；完成后在消息流插入摘要条 |
| 恢复 | 展开摘要条 →「恢复这段原文，摘要将失效」，或右栏压缩历史里的「恢复」 |
| 深浅色 | 顶栏右上角月亮图标 |

界面上**没有头像**（消息、会话列表、空态、右栏一律没有），归档消息只以轻微降透明度区分、不带「已归档」标签；会话列表**不按今天/昨天分组**，只有「已置顶」段（有置顶时才出现）与其余全部会话，后者按更新时间倒序。

## 与设计稿的差异（Demo 才有）

- 「角色库 / 人设 / 设置」三个导航项只展示占位页——Demo 聚焦对话界面与左栏交互。
- 「编辑角色卡」「人设管理」只弹提示，不实现。
- 模型回复取自固定话术（按关键词与字符哈希选择），不调用任何模型。
- 压缩进度为定时器模拟，摘要正文为模板拼装。

## 自检

```bash
npm run verify:demo   # 结构 / 脚本语法 / 离线可用性 / 关键交互 / 标签配平 / 选择器引用
npm test              # 27 项校验器与文档测试
```
