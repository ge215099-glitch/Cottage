# 前端重设计方向

更新：2026-11-23。用户明确要求整体重构界面，并确认取消对话搜索、保留直接可见的右侧栏、移除设备存储说明和输入快捷键说明。左右侧栏按钮各自固定位置，收放保持平滑过渡；角色库与表单保持文案简洁。审美基准仍为原始 `FrontendDemo` 的 ChatGPT 简约风格。

## 视觉与布局

- 白色正文、浅灰导航和浅灰详情栏；深色对应 #212121 正文、#171717 导航和 #1b1b1b 详情。使用适合中文阅读的系统字体、细线图标、柔和选中态与低对比分隔，不添加渐变、纹理或装饰动画。
- 窗口顶栏与左栏同色，高度固定为 40px，在普通窗口、最大化和全屏下保持一致。顶栏放置独立的左栏开关和加粗的「Cottage」文字，空白处可拖动窗口，保留系统窗口控制按钮。
- 左栏放置新对话、角色库、会话列表与底部设置。取消搜索输入、搜索快捷键和「对话保存在此设备」。保留置顶分组与会话重命名、置顶、删除菜单。
- 左侧栏使用顶栏的同一个按钮收起和展开。宽窗口以宽度与内部位移、窄窗口以整栏位移在约 260ms 内滑动；侧栏内部包含自身留白，按钮与会话操作不得被右边界裁切，会话列表独立滚动，设置始终在底部。
- 角色库卡片只展示封面与名称；搜索和筛选入口保持紧凑，标签多选与收藏条件收在同一个筛选面板。角色详情在封面右侧、名称下方显示标签，标签自动换行。资料区独立滚动，主要操作固定在弹窗底部并始终可见。编辑表单和新对话选角只保留字段、搜索及必要状态，不增加解释段落。
- 角色库包含「我的卡片」和「Chub 搜索」，默认显示前者。两个标签的工具栏和卡片网格对齐，切换时预留滚动条空间。Chub 工具栏只显示搜索框、「搜索」和「在 Chub 打开」。公开角色卡默认按热度加载，支持翻页和预览，在预览中可以导入当前卡片。JSON / PNG 文件导入入口位于「我的卡片」。
- 角色详情底部提供「转换语言」，可选择中文或中英双语、模型连接及锁定词。生成与预览共用一个弹窗，长预览独立滚动。角色库、角色详情和新对话选角用「中文」或「双语」区分副本。
- 中栏顶部显示会话标题与实际生效模型；详情使用同一个固定在窗口右上角的开关，展开、收起前后位置不变，不显示重复的「详情」按钮。取消原顶栏会话三点菜单。
- 聊天正文居中，最大阅读区域 780px；用户使用浅灰气泡，角色回复开放排版。消息工具放正文下方，悬停或键盘焦点出现。输入框与阅读区对齐，取消底部 Enter / Shift+Enter 提示，发送行为和输入法保护保留。
- 双语角色的新回复按自然段配对，每组先英文，下一行接对应的简体中文，组间留一行。角色卡的开场白和对话示例仍按句对照。
- 流式回复等待首字时显示柔和呼吸的小圆点，正文出现后移除圆点，不附加闪烁光标。收到的文本以短缓冲平滑呈现，完成、停止和错误终态立即显示全部已收到文本；系统开启减少动态效果时直接展示。正文增高时跟随底部，上翻阅读时不抢滚动位置。
- 重做首页为空间简洁的「今天，想和谁聊聊？」入口，提供新对话、角色库与模型连接。

## 右侧详情栏

默认展开并显示当前角色；四个直接入口按角色、对话、记忆、导出排列。它是与中栏并排的真实侧栏，不是对话框，不遮住聊天，不限制焦点在栏内。右上角同一个按钮始终固定原位，Ctrl+I 仍可切换；侧栏以约 260ms 的宽度和位移过渡平滑收放，系统开启减少动态效果时立即切换。

| 分类 | 内容 |
| --- | --- |
| 角色 | 角色图片或中性占位、名称、标签、可折叠的简介（初始展开）、背景与系统提示；不提供角色库编辑入口 |
| 对话 | 当前人设、折叠的高级参数、重置与保存；输出 token 输入去掉加减箭头，可清空重输，空框提示 1–1,000,000（整数），空值和非法值禁用保存；新会话默认 8,192，已有设置保留。实际上限取决于模型；保存后保持侧栏打开 |
| 记忆 | 上下文占用与估算标记、自动整理状态、手动整理、摘要与恢复、折叠技术明细 |
| 导出 | Markdown、JSON、复制全文、经确认的重新开始及删除 |

收起侧栏、切换分类都保留未保存的会话设置。聊天草稿和后台任务独立于侧栏。切换会话重新初始化该会话设置，避免把上一会话的表单写给新会话。恢复与重开仍需后果确认，不提供主进程尚未支持的「取消整理」。

角色标签与简介之间只保留简介折叠区的一条分割线。侧栏的折叠标题不可选中文字，正文仍可选择复制。滚动区预留对称的滚动条空间，展开长内容出现滚动条时，角色信息、标签和标题不左右移动。

## 比例与自适应

- 常规窗口：左栏 236px、右栏 300px；1500px 以上分别为 252px、320px。
- 1120px 以下：左栏 210px、右栏 272px，缩小正文水平内边距。
- 900px 以下：左栏作为可关闭的覆盖导航；右栏仍并排，占 250px。720px 以下右栏缩为 224px，分类图标与文字上下排列。可独立收起右栏扩展聊天空间。
- 长会话标题和模型名省略显示，正文、代码块和表格在各自区域内换行或滚动。

## 行为与验证

- 设置按用户提供的 DeepSeek 截图改为居中圆角面板，背景变暗并轻微模糊；左侧纵向分类、右侧独立滚动，不再替换整个聊天页面。分类为通用设置、模型连接、我的人设、用量；保留 Cottage 现有能力，不添加登录或账号管理。
- 通用设置使用浅色、深色、跟随系统三张主题卡片；其余偏好以分隔行排列。默认面板 960×640px，随窗口约束尺寸。
- 模型连接在所有宽度统一使用紧凑列表，仅保留名称、简短状态及测试、编辑、删除按钮；不显示地址、模型明细、密钥掩码、创建或使用日期。成功结果仅显示带勾的绿色「测试通过」提示，失败仅显示「鉴权失败」或「连接失败」，不展示 HTTP 状态和原始测试报告。完整配置在编辑窗口中管理。
- 关闭设置（关闭按钮、Escape、点击遮罩）返回原页面并恢复入口焦点；聊天、右栏表单与草稿保持挂载。设置内的创建/编辑弹窗单独处理焦点，Escape 只关闭最上层。

- 输入法确认不发送；发送前失败保留草稿；后台生成和整理按会话管理。
- 滚动保留阅读位置，查看历史时不抢滚动；设置页返回与开关右栏不主动清空草稿。
- 右栏分类支持方向键、Home、End；在侧栏内按 Escape 关闭并返回固定的详情开关。收起时栏内控件不可聚焦，表单继续保留。真正的确认弹窗继续限制焦点并在关闭后恢复。
- 不增加模拟模型回复、附件、语音、登录等没有业务支持的功能。
- 布局验收必须使用真实渲染窗口。自动测试用于验证入口、草稿、保存、并发任务与发送行为，不替代视觉验收。实际检查记录见 [实现记录](implementation-status.md)。
